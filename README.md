# Echos der Magna Graecia

Dieses Repository enthält ein Phaser‑3 Starterprojekt für ein kleines Schulspiel (deutsche Texte) mit einer Karte von Magna Graecia, Knoten‑Szenen, einfachen Echtzeitkämpfen und Quest‑Logik.

Kurzanleitung

1. Lokale Entwicklung
- Am einfachsten: einen lokalen HTTP‑Server starten (z. B. mit Python):
  - Python 3: python -m http.server 8000 (im repo/docs Verzeichnis)
  - Öffne http://localhost:8000

2. GitHub Pages
- Das Spiel ist im Ordner `docs/`. Aktiviere GitHub Pages in den Repository‑Einstellungen und wähle den Branch `dev` und Ordner `/docs` (oder du kannst die Inhalte in den `main` Branch pushen und `docs/` als Quelle wählen).

3. Dateien
- docs/: statische Spiel‑Dateien (index.html, src, data)
- README.md: Anleitung
